## A — strong single-pass prompt

In a clean session outside this repository, without loading the skill, its AGENTS.md,
or any generated outputs: “Address the supplied research task using the allowed evidence
and budget. Check whether the problem exists, search for the closest methods and relevant
transferable mechanisms, challenge the proposed contribution, and design a feasible test
that could falsify it. Link factual assertions to located evidence; distinguish fact,
inference and hypothesis, and source existence from support. Preserve all resource and
temporal constraints. Never fabricate literature or new results. Report uncertainty,
negative findings, and no recommendation when justified. Produce a single final report.”

## B — staged, without cross-problem mechanism search

Use the same brief/evidence/review/report stages and evidence standards as C. Disable

## C — full skill

judge notes. A common evaluator measures evidence support from final reports; any
conversion into evaluation format occurs only after generation, with no content repair.

network is disabled for every condition. Live retrieval is a separately labeled study.
Stop after the cap in every arm. Do not compare unlimited C with retrieval-free A.
